# Roadmap

0. **Feasibility:** official constraints, product cuts and protocol.
1. **Foundation:** PRD, ADRs, schema/API, threat/privacy models.
2. **Internal MVP:** manual track picker, discovery simulator/QR, matching, consent state machine, chat, block/report, analytics.
3. **Device pilot:** native BLE adapters, physical-device matrix, invite cohort, admin moderation and staging.
4. **Controlled pilot:** 150-500 adults, four weeks, weekly safety/product review.
5. **Decision:** improve density/value if thresholds miss; scale only after repeat meaningful connections.
6. **Post-proof:** provider approvals, campus/concert partner mode, taste matching, Hindi, stronger trust, extracted services only when justified.

Flight/metro modes, minors, universal sync, communities, creator monetization and global launch are explicitly not MVP promises.
