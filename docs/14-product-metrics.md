# Product metrics

North star: Meaningful SYNQ Connections / WAU, defined in the PRD. Every event includes schema version, anonymous analytics subject, timestamp, app/build, pilot and experiment; never exact coordinates, message body, raw BLE token or provider credential.

Dashboard: eligibility -> permission -> music -> discovery -> candidate -> viewed -> requested -> accepted -> reciprocal conversation -> repeat discovery. Segment by pilot and platform, with minimum cohort sizes. Guardrails: block/report, false-proximity feedback, crash-free sessions, battery complaints, p95 latency and moderation SLA. Experiments must name a hypothesis and stop condition.
