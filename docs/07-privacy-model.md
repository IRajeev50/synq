# Privacy model

Purpose limitation: create an adult pilot account, enable a user-controlled discovery window, compute minimal music compatibility, support mutual connections/chat, and operate safety. No targeted advertising or location history.

Legal basis and India DPDP obligations require counsel. Product controls include clear notice/consent, access/export, correction seam, deletion, grievance contact, processor contracts and breach response. International launch requires regional assessment.

See `docs/privacy/data-retention.md` for the data schedule. Provider scopes and BLE permissions are optional and revocable. A profile is never visible merely because a radio token was observed.
